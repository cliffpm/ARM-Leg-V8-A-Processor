# ARM-Leg-V8-A-Processor
A 64 bit ARM Leg-V8-A 5 staged pipeline CPU implementation in SystemVerilog that is capable of executing 25 ARM instructions. The top level code of the processor is inside 'cpu.sv', and other support code files are included in this repository as well. The schematic below is what I used to reference while building the processor.
